Como funciona

Um bloco de cada vez

Cada bloco só abre quando o anterior estiver concluído. Se já dominas os temas de um nível, podes entrar diretamente nele e a escolha fica registada.

Diz-te o que preparar

Cada bloco abre com o que precisas de ter instalado. Os poucos exercícios que podem custar dinheiro dizem-no à partida, e são saltáveis.

As trilhas conversam

O bloco de caching em System Design aponta para o projeto de Redis em Go. Uma explica o porquê, a outra põe as mãos na massa.

O progresso é teu

Fica guardado no teu browser, sem conta e sem servidor. Como é local, não passa de um dispositivo para outro.
